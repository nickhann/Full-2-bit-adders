# 2-Bit Full Adder Breadboard Project

A 2-bit full adder built using TTL logic ICs on a breadboard. Two 2-bit binary numbers are entered through a DIP switch bank, and the resulting sum is displayed on an LED output module.

# How It Works

The circuit adds two 2-bit binary numbers:

```text
A = A1A0
B = B1B0
```

The least significant bit is processed by a full adder with its carry-in tied to logic 0. The carry-out generated by this stage is connected to the carry-in of the second full adder, allowing carries to propagate between bits.

The output consists of:

```text
S0 = Least significant sum bit
S1 = Most significant sum bit
Cout = Final carry-out bit
```

The result is displayed as:

```text
Cout S1 S0
```

allowing values from:

```text
000₂ (0)
```

to

```text
110₂ (6)
```

to be represented.

The circuit operates continuously in real time. Changing any input switch immediately updates the output without requiring a clock signal or execute button.

# Inputs and Outputs

## Inputs

A DIP switch bank is used to enter two 2-bit binary numbers:

```text
A1 A0
B1 B0
```

Example:

```text
A = 11₂
B = 01₂
```

---

## Outputs

An LED module displays:

```text
Cout S1 S0
```

Example:

```text
11₂ + 01₂ = 100₂
```

Output:

```text
Cout = 1
S1 = 0
S0 = 0
```

# Design Overview

The project uses two cascaded full adders.

```text
        A1 A0
        B1 B0
         │  │
         ▼  ▼

     ┌─────────┐
     │ Full    │
     │ Adder 0 │
     └─────────┘
          │
       Carry

          ▼

     ┌─────────┐
     │ Full    │
     │ Adder 1 │
     └─────────┘

          │
       Cout
```

The carry-out from the first stage becomes the carry-in of the second stage. This demonstrates carry propagation, which is the fundamental principle used in larger ripple-carry adders.

# Component Choices

The project was constructed using standard digital logic ICs and a breadboard power supply module.

The output display was implemented using an LED display module for immediate visual feedback during testing.

A DIP switch module was selected for the inputs to allow binary values to be changed without rewiring the circuit.

# Challenges Encountered

During assembly, the primary challenge was ensuring that the carry output of the least significant full adder was correctly connected to the carry input of the next stage.

Additional testing was performed to verify that:

- Input switches generated the expected binary values.
- Sum outputs matched manual binary addition.
- Carry propagation occurred correctly between stages.
- The output display accurately reflected the final result.
